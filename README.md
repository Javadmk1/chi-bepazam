# چی بپزم؟ | Chi Bepazam

اپلیکیشن اندرویدی پیشنهاد غذا و مدیریت مواد غذایی با رویکرد آفلاین‌محور.

## فناوری‌ها
- Expo + React Native + TypeScript
- SQLite برای نگهداری داده‌ها روی دستگاه
- Zustand برای مدیریت وضعیت
- GitHub Actions برای اعتبارسنجی و ساخت APK آزمایشی

## قابلیت‌های پیاده‌سازی‌شده
- رابط فارسی راست‌به‌چپ با تم زغالی، طلایی و سبز
- خانه، پیشنهاد غذا، انبار، دستور پخت، برنامه هفتگی، لیست خرید و تنظیمات اولیه
- ذخیره محلی مواد غذایی و اقلام خرید
- نرمال‌سازی اولیه نام مواد با نام‌های جایگزین فارسی و انگلیسی
- مرتب‌سازی پیشنهادها بر اساس میزان مواد موجود و زمان پخت
- افزودن غذا به برنامه هفتگی و حذف آن با نگه‌داشتن روی وعده
- ساخت لیست خرید از برنامه هفتگی با تجمیع مواد و کسر یک‌باره موجودی انبار
- انتقال اقلام خریداری‌شده به انبار
- ثبت و ویرایش مقدار و تاریخ انقضای مواد، با هشدار مواد منقضی و نزدیک به انقضا
- مقیاس‌کردن مقدار مواد دستورها بر اساس تعداد نفرات
- کاتالوگ ۱۵۰ غذای دارای ۷۰۱ مقدار ماده اولیه و مراحل پخت
- یکسان‌سازی واحد مواد دستورها با واحد پایه انبار و جلوگیری از جمع‌زدن مقادیر ناسازگار
- پشتیبانی تصویر محلی غذا با بازگشت خودکار به ایموجی در نبود تصویر\n- اسکریپت دریافت عکس غذا از Wikimedia Commons با مجوزهای آزاد مجاز، ساخت نقشه تصاویر برای Metro و فایل انتساب مجوزها؛ این مرحله در ساخت APK اجرا می‌شود
- اعتبارسنجی خودکار تعداد غذاها، یکتایی شناسه‌ها، مواد اولیه و مراحل دستور در CI
- کاتالوگ شروع شامل دستورهای غذای ایرانی

## اجرای محلی
نیازمند Node.js 20 یا بالاتر:
```bash
npm install
npx expo start
```

## ساخت APK آزمایشی از GitHub با گوشی
1. وارد مخزن GitHub شوید.
2. به تب Actions بروید.
3. گردش کار **Build Android test APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از پایان موفق، از بخش Artifacts فایل `chi-bepazam-debug-apk` را دریافت کنید.
6. APK داخل ZIP را روی گوشی نصب کنید.

این خروجی برای تست داخلی است؛ نسخه انتشار فروشگاهی نیست و هنوز باید روی چند دستگاه واقعی آزمایش شود.

## وضعیت فعلی و کارهای باقی‌مانده
- مقادیر بعضی مواد با تبدیل‌های تقریبی پیمانه/وزن ثبت شده‌اند و باید با دستورهای آزموده‌شده بازبینی شوند.
- تصاویر واقعی اختصاصی غذاها هنوز تهیه و داخل بسته آفلاین برنامه قرار نگرفته‌اند؛ فعلاً ایموجی جایگزین است و مسیر تصویر اختیاری آماده شده است.
- فیلتر حساسیت فعلاً تطبیق نامی ساده است و هنوز فرهنگ جامع آلرژن‌ها و آلودگی متقاطع را پوشش نمی‌دهد.
- بودجه هفتگی هنوز در محاسبه پیشنهادها و لیست خرید اعمال نشده است.
- آخرین دریافت خودکار Wikimedia در CI فقط ۱۱ تصویر از ۱۵۰ غذا را پیدا کرد؛ برای بقیه غذاها فعلاً ایموجی جایگزین است. عکس‌ها اختصاصی تولید نشده‌اند و باید گزارش و انتساب مجوزها بررسی شوند.
- نسخه فعلی کاملاً آفلاین است؛ حساب کاربری، سرور و همگام‌سازی ابری ندارد.
- داده‌های کاربر در SQLite روی همان دستگاه ذخیره می‌شوند و با حذف داده‌های برنامه ممکن است پاک شوند.
- ساخت APK از GitHub Actions پیکربندی شده است؛ وضعیت آخرین اجرای workflow را در Actions بررسی کنید. نصب و تست روی گوشی واقعی هنوز تأیید نشده است.
